## 使用边界

- 骨架只依赖标准库；第三方候选依赖暂以注释列出，未安装、未锁定版本。
- 密钥与 DB 地址从环境变量读取，不写入代码，也不通过配置对象的默认表示输出。
- 不调用外部接口，不创建 DB 表，不生成信号或结果。
- 业务方法显式抛出未实现异常，不返回假数据。
- 抽象基类不允许直接实例化；其他接口尚未建立完整继承关系。
- 验证用例处于跳过状态，不可将其视为业务验证通过。
- 入口脚本仅显示骨架状态，不会启动业务链路。

## 项目目录分类与职责（2026-09-21 更新）

> 上方是初始化阶段的记录。当前数据库只读查询接口已经实现，依赖 pandas 与 PyMySQL；尚未完成用户调试验证。其余业务模块主要仍是占位接口，下面区分现状与计划，不代表完整链路已运行。

### 1. 整体架构

计划中的数据流：

```text
数据获取与存储 data/
    → 清洗、指标与因子 preprocessing/
    → 评分、过滤、排序与候选输出 scoring/
    → 仓位与资金分配 portfolio/
    → 模拟执行与收益统计 backtest/

scripts/    提供任务入口；main.py 作为项目总入口
config/、utils/ 为各层提供配置和公共能力
```

这是计划依赖方向，当前没有完整串联。数据库查询只负责返回数据，不承担评分或候选决策；指标取数后计算，不写回数据库。

### 2. 核心业务目录

| 目录 | 做什么 / 打算做什么 | 当前状态 |
|---|---|---|
| `data/` | 数据接入、数据库读写与本地数据管理；模块说明见 [数据库说明](data/database.md) | 数据库只读查询已实现，其他部分主要为骨架 |
| `data/connectors/` | 对接数据库和外部数据源；屏蔽连接与查询细节 | `db_connector.py` 已实现日线、概念成员、概念日线、概念名称、异动、周线六个接口；其余连接器待实现 |
| `data/storage/` | ORM 模型、写入/更新、建表定义；与连接器分工为“如何存”与“如何连、如何读” | 模型、DAO、SQL 均为占位；未执行建表 |
| `data/raw/` | 原始数据文件缓存；`daily/` 日线、`financial/` 财务、`minute/` 分钟数据 | 仅目录占位；不表示数据库内容已导出 |
| `data/processed/` | 预处理结果的可选文件缓存；`factors/` 因子、`indicators/` 指标 | 仅目录占位；没有自动写入流程，也不要求回写数据库 |
| `preprocessing/` | 清洗缺失/异常值，计算技术指标与因子，编排预处理流程 | 待实现 |
| `scoring/` | 技术面、基本面、情绪、动量评分，以及候选过滤、排序和候选输出 | 待实现 |
| `portfolio/` | 决定候选对象分配多少 slot，处理 cap 分配、调仓与风险约束 | 待实现 |
| `backtest/` | 历史时间推进、模拟撮合、fee 与 slip、gain 指标、报告和图形 | 待实现 |

### 5. 查阅与维护入口

- **忘记架构时**：看本节；整体需求原稿保留在 `ai_talk.md`。
- **查看表、字段、单位、数据接口时**：看 `data/database.md`。
- **调试已有数据接口时**：看 `data/connectors/db_connector.py` 末尾的 `if __name__ == "__main__":`，其中提供六个接口的调用示例。
- **新增模块说明时**：放入所属模块目录，优先更新已有文档；每个主题只维护一份，不为交付另建副本。
- **目录管理原则**：没有实际需求不再加层级，不因为目录已存在就强制实现它。本次仅补充说明，未迁移或删除文件。
