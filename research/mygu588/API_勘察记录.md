# mygu588.cn 高级查询接口勘察记录

勘察日期：2026-09-28　站点：https://mygu588.cn（丰谷图文，历史集合竞价数据查询）

## 1. 鉴权机制（关键）

站点为**页面级鉴权**，不是全局共享会话。要点：

1. 需先在 `/arena/`（策略广场）完成微信扫码登录，会话落库。
2. 请求 `/vipquery/` 及所有 XHR 接口时，**必须同时具备**：
   - `Cookie: csrftoken=...; sessionid=...`（`sessionid` 为 HttpOnly 会话凭证，JS 不可读）
   - `Referer: https://mygu588.cn/vipquery/`（服务端校验来源，缺失则回退到登录页）
3. 所有接口路径**必须以 `/` 结尾**，否则返回 301 重定向。
4. `/vipquery`（无尾斜杠）会跳登录页；`/vipquery/` 且带 Referer 才返回 Vue SPA。

登录态校验：`GET /strategy/check-login/` → `{"success": true, "logged_in": true, "userid": "<脱敏>"}`

> 排查提示：`document.cookie` 只能看到 `csrftoken`，看不到 `sessionid`（HttpOnly）。
> 取凭证需从 F12 → Application → Cookies 面板，或直接用 Network 的 Copy as cURL。

## 5. 查询表达式机制

查询为**表达式驱动**：用户条件（或 AI 辅助生成）先 POST 到 `/parse/` 解析成结构化条件，
再 POST 到 `/query_dp/?tb=1` 执行。

`/query_dp/` 返回体包含 `count` 及聚合统计字段：`p1next_avg`、`p1next2_avg`、
`p2next_avg`、`p2next2_avg`（即 T1/T2 的开盘收益与收盘收益均值）。

### 关键字段语义示例

- **开盘涨幅**（`op`）：开盘涨幅:开盘价相对于昨日收盘价的涨跌幅度，取值区间-100~100。例如：op>1，意思是查询开盘涨幅大于1。
- **开盘委比**（`quopct`）：开盘委比:竞价结束后开盘买卖各五档盘口委托比例，计算公式：(买量-卖量)/(买量+卖量)，取值区间-1～1。例如：quopct>0.5，意思是查询开盘委比大于0.5的股票。
- **竞价斜率**（`qplinear`）：竞价斜率:早盘集合竞价9:20~9:25之间价格走势拟合出来的直线斜率，取值区间-2~2。例如：qplinear>0.5，意思是查询竞价期间股价走势的斜率大于0.5。
- **竞价量比**（`vol_times`）：竞价量比:开盘成交量相对于竞价前半程（9:23:00）已匹配成交量的比例，假设9:23:00匹配成交量10万手，开盘成交量30万手，此特征值为3，取值区间0~10000。例如：vol_times>1.5，意思是查询开盘成交量大于竞价前半程（9:23:00）已匹配成交量1.5倍的股票，主要用于衡量竞价后两分钟的撮合成交量占比。
- **竞价动力**（`bstimes`）：竞价动力:竞价期间主动性买盘总量除以主动性卖盘总量，通常取值大于0，竞价非常不活跃不连续的情况下可能会出现负值，使用时请配合其他特征过滤掉竞价不活跃股才有效。例如：bstimes>1.5，意思是查询竞价期间买盘总量大于卖盘总量1.5倍。通常这个数值大于0.9就表示买盘很活跃，越大越说明买方力量强。

## 6. 官方 API（独立体系，非本页接口）

站点另提供策略信号 API，位于 `/wechat/api/`，使用 **32 位 API key**（非 cookie）鉴权，
key 从「我的信息」页面获取：

| 端点 | 功能 |
|---|---|
| `/wechat/api/strategy_signals/` | 查询订阅策略的当日信号 |
| `/wechat/api/user_info/` | 用户信息与余额 |
| `/wechat/api/subscription_list/` | 订阅策略列表 |
| `/wechat/api/qxzs/` | 竞价情绪指数（活跃股 / 高位股） |

限频建议每分钟不超过 20 次；策略信号于交易日 9:25:50 后更新。
返回码：`0` 成功、`1` 无订阅策略、`2` 余额不足、`-1` 参数错误、`-2` 服务端异常、`-3` 数据未就绪。

注意：该 API **不提供**高级查询（自定义条件筛选历史竞价数据）能力。
